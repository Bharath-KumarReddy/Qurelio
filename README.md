
# SetUp
 `git clone https://github.com/Bharath-KumarReddy/Qurelio.git`
## Frontend 
 `cd Client ` <br>
 `npm install` <br>
 `npm run dev` <br>
## Backend node server
create a config.env file in Server folder, add all required env variables <br>
 `cd Server` <br>
 `npm install` <br>
 `npm run start` <br>
## Backend Python server
 `cd Server` <br>
 `pip install -r requirements.txt` <br>
 `python app.py`
